# Cihê nîşankerê

* Nivîskar: Noelia Ruiz Martínez, Sergio Gómez Codina.

Ev pêvek dihêle ku meriv dema nivîsandinê ji bo zêdekirina nivîsê li belgeyan an kontrolên pir-rêzî, pozîsyona kareta sîstemê li gorî destpêka rêza heyî bizanibe.

Ev taybetmendî bi xuyabûna dîtbarî ya sepanan ve girêdayî ye. Ji ber vê yekê, dibe ku hûn hewce bikin ku sererastkirina xêzan neçalak bikin an jî pêveka ji bo bernameyên cûda mîheng bikin.

## Mîhengên Cihê Kursorê

Ev panel ji pêşeka NVDA, jêr-menûya Tercîhan û pencereya diyaloga Mîhengan peyda dibe.

Ew vebijarkên jêrîn peyda dike:

* Dirêjahiya rêzê rapor bike: Hûn dikarin dirêjahiya rêzê binivîsin an hilbijêrin (hejmara tîpan di navbera 0 û 600 de), ku dema ku bigihîje wê bi dengekî bilind dê were ragihandin. (Nirxa xwerû 80 tîp e).
* Hejmara herî zêde ya bipên ji bo agahdariya destpêka rêzê: Hûn dikarin nirxek di navbera 0 û 600 de binivîsin an hilbijêrin. Nirxa xwerû 0 e.
* Hejmara herî zêde ya bipên ji bo agahdarkirina dawiya rêzê: Hûn dikarin nirxek di navbera 0 û 600 de binivîsin an hilbijêrin. Nirxa xwerû 0 e.
* Bilindahiya dengê destpêka rêzê: Hûn dikarin nirxek di navbera 20 û 20000 de binivîsin an hilbijêrin. (Nirxa xwerû 400 hertz e).
* Dirêjahiya deng ji bo destpêka rêzê: Hûn dikarin nirxek di navbera 20 û 2000 de binivîsin an hilbijêrin. (Nirxa xwerû 50 milîçirke ye).
* Dengê destpêka xetê biceribînin: Ji bo ceribandina dengê destpêka xetê, vê bişkojkê bikirtînin.
* Bilindahiya deng ji bo dawiya rêzê: Hûn dikarin nirxek di navbera 20 û 20000 de binivîsin an hilbijêrin. (Nirxa xwerû 1000 hertz e).
* Dirêjahiya deng ji bo dawiya rêzê: Hûn dikarin nirxek di navbera 20 û 2000 de binivîsin an hilbijêrin. (Nirxa xwerû 50 milîçirke ye).
* Dengê dawiya rêzê biceribînin: Ji bo ceribandina dengê dawiya rêzê, vê bişkojkê bikirtînin.

## Ferman

Hûn dikarin bi rêya menûya NVDA, binmenûya Tercîhan, û diyaloga Têketina Jestan jestan li gorî fermanên jêrîn biguherînin:

* NVDA+control+shift+l: Dema ku gengaz be, dirêjahiya xeta heyî radigihîne (kategoriya bişkoka sîstemê).
* Nehatiye destnîşankirin: Paceya diyalogê ya mîhengên Cihê Kursorê nîşan dide (Kategoriya Mîhengkirinê).
